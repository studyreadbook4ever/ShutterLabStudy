# 실험 가이드

모든 실험은 Global과 Rolling이 같은 장면·중앙 시각·렌즈·노출을 공유하는 비교입니다. 렌즈나 물체를 바꾸면 양쪽에 함께 적용됩니다. 재생을 멈추고 변수 하나씩 바꾸면 원인을 구분하기 쉽습니다.

## 1. 시간 왜곡 확인

기본 실험에서 막대를 선택하고 재생을 멈춥니다. 읽기 시간을 0 ms로 바꾸면 두 셔터의 촬영 조건이 같아집니다. 읽기 시간을 올리면 화면의 위아래 행이 다른 시각의 막대를 기록합니다. 읽기 방향을 바꾸고 중첩·차이 화면을 보면 판독 순서의 영향을 비교할 수 있습니다.

고속 회전 프리셋에서는 480 rpm와 35 ms의 조합이 전체 센서 판독 구간에 약 **100.8°**의 회전을 만듭니다. 이 수치는 각도 변화이며 픽셀 오차가 아닙니다. 실제 영상에서는 막대의 자세·기울기·시야각도 결과에 영향을 줍니다.

## 2. 형상에 따른 차이

같은 속도·토크·읽기 시간을 유지한 채 막대, 프로펠러, 사각 프레임, 바퀴를 바꿉니다. 선택 시 권장 관성이 적용되므로, 형상만 비교하려면 매번 관성을 같은 값으로 다시 맞춥니다. 직선이 많은 형상과 회전 대칭이 강한 형상에서 왜곡이 어떻게 나타나는지 비교합니다.

회전 대칭은 움직임을 숨길 수 있습니다. 바퀴의 외곽만 보지 말고 스포크와 표시를 관찰하세요. 권장 관성은 형상·질량에서 유도한 값이 아니라 실험 시작값입니다.

| 물체 | 선택 시 관성 (kg·m²) |
| --- | --- |
| 막대 | 0.5 |
| 프로펠러 | 0.7 |
| 사각 프레임 | 0.8 |
| 바퀴 | 0.6 |

## 3. 렌즈 왜곡과 시간 왜곡

어안 렌즈 프리셋을 선택합니다. 먼저 속도와 토크를 0으로 설정하면 움직임이 없어지고 렌즈 투영만 관찰할 수 있습니다. 고정된 배경 격자가 Pinhole과 Fisheye에서 어떻게 다르게 보이는지 확인하세요.

물체가 광축 중심을 지나는 경우 일부 직선은 방사형 어안 투영에서도 직선으로 남습니다. 중심 오프셋을 바꾸면 렌즈의 곡률을 보기 쉽습니다. 다시 속도를 올리면 렌즈 투영 위에 행별 촬영 시각의 차이가 더해집니다.

## 4. 모션 블러

긴 노출 프리셋에서 노출 시간을 바꿉니다. 읽기 시간은 행별 노출의 **시작 관계**를 정하고, 노출 시간은 각 행이 빛을 **누적하는 길이**를 정합니다. 읽기 시간을 0으로 설정해도 유한한 노출 동안 움직이는 물체에는 블러가 생깁니다.

시간 샘플 수를 줄였다가 늘려 보세요. 1개 샘플은 노출 중앙의 한 자세만 평가하므로 연속적인 블러를 재현하지 못합니다. 여러 샘플은 노출 구간을 근사하지만 매우 빠른 회전이나 긴 노출에서는 잔상이 남을 수 있습니다.

## 5. 가속과 감쇠

토크를 주면 `τ/I`가 회전을 가속합니다. 감쇠가 있을 때는 속도가 `τ/b`로 접근합니다. 토크가 0이고 감쇠가 양수이면 속도와 운동 에너지가 감소합니다. 관성을 늘리면 같은 토크에 대한 가속도가 작아집니다.

최초 rpm 설정과 현재 rpm 측정값을 구분하세요. 토크·감쇠가 있으면 재생 중 현재 속도가 변합니다. 읽기 중 회전량도 현재 상태에서 계산됩니다.

## 저장과 재현

실험을 JSON으로 저장하면 물체·물리·카메라 설정과 순간 상태를 다시 불러올 수 있습니다. 불러온 실험은 일시정지 상태에서 확인합니다. PNG는 실제 표시된 비교 프레임을 저장합니다.

| 기록 | 비교할 때 필요한 이유 |
| --- | --- |
| JSON 파일 | 물체와 운동·카메라 조건 및 순간 상태 재현 |
| 렌더러 이름 | WebGL2와 CUDA의 구현 차이 구분 |
| PNG 결과 | 관찰한 프레임 공유 |
| 현재 rpm과 시뮬레이션 시각 | 가속·감쇠 실험의 순간 확인 |
| 시간 샘플 수 | 블러 근사 품질 비교 |

재생 배속은 시뮬레이션 시계의 진행을 바꿉니다. 센서 읽기·노출 시간 자체를 바꾸지는 않습니다. 같은 촬영 조건의 결과를 비교할 때는 재생을 멈추고 프레임을 고정하세요.
